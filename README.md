# NSF Website - Information for Undergraduates

A modern, responsive website for the National Science Foundation's undergraduate funding information page.

## 🚀 Quick Deploy to Vercel

This project is configured to deploy automatically to Vercel.

### Steps:

1. Clone this repo to your local machine (or download as ZIP)
2. Upload all files to your GitHub repository: nsf-website
3. Vercel auto-detects and deploys automatically
4. Get your live URL in ~30 seconds
